Document metadata includes hidden information embedded in files — author names, creation dates, GPS coordinates (in images), revision history, software versions, and internal comments. Yes. Beyond fixing structural corruption, the repair tool applies OCR (Optical Character Recognition) to scanned or image-based PDFs. This converts visual content into real, searchable, selectable, and copiable text — all in one step, without a separate OCR tool.

This happens when a PDF was created from a scan or a photo — the text is an image, not real characters. Use the Repair & Rebuild tool with OCR enabled: it will convert that image-text into real, copiable text without needing any separate software.

Yes, redaction is permanent and forensically sound. The tool finds keywords or regions you specify and replaces them with solid black bars, then flattens the PDF so the hidden content cannot be extracted or recovered. This is suitable for legal, compliance, and court submission use cases.

The Encrypt PDF tool applies AES-256 encryption with a password you set. It supports both user password (required to open the file) and owner password (controls printing, copying, and editing permissions). The encryption is fully compatible with Adobe Acrobat and all standard PDF readers.

Flatten PDF converts all interactive elements (form fields, annotations, signatures) into static content — the visual appearance is preserved but the elements become non-editable. Repair PDF fixes structural corruption in the file itself (broken cross-reference tables, truncated streams) and optionally applies OCR to make text selectable. They solve different problems and can be combined in the pipeline.
