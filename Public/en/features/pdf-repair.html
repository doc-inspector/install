What It Does

What Gets Repaired

DocInspector's PDF Rebuild engine handles the most common failure modes that make PDFs unreadable or corrupt.

📋

Cross-Reference Table Errors

Rebuilds the xref table from scratch — fixes PDFs where page offsets are broken, making the file open blank or crash viewers.

🔗

Broken Internal Links

Repairs broken object references between pages, fonts, images, and annotations that cause partial rendering.

🖼️

Smart OCR for Scanned Pages

Detects image-only pages (scans, faxes) and runs optical character recognition — making text selectable and searchable.

📦

Truncated / Incomplete Files

Reconstructs PDFs that were cut off mid-transfer — recovers all pages that have valid data even if the file ends abruptly.

🔒

Password / Permission Conflicts

Strips conflicting security settings that prevent normal editing or printing even when no password is set.

⚙️

Malformed Stream Objects

Fixes incorrectly encoded streams (FlateDecode, DCTDecode) that cause garbled text or missing images.
