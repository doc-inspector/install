GDPR Document Compliance Checklist 2025

2026-06-30  ·  By DocInspector Team

GDPR isn't just about websites and databases — it applies to every document containing personal data, including PDFs. In 2025, supervisory authorities are increasingly scrutinizing document management practices. Here's your complete compliance checklist.

What Counts as Personal Data in Documents?

Any information that identifies or can identify a natural person:

  • Names, addresses, phone numbers, email addresses
  • ID numbers, passport numbers, tax IDs
  • IP addresses, cookies, location data (in digital documents)
  • Photos, biometric data
  • Health, financial, political, religious data
  • And metadata containing any of the above

GDPR Document Compliance Checklist

Lawful Basis & Purpose Limitation

  • ☐ You have a lawful basis for processing the personal data in this document
  • ☐ Data is used only for the purpose it was collected
  • ☐ Document purpose is documented in your records of processing activities (RoPA)

Data Minimization

  • ☐ Only necessary personal data is included in the document
  • ☐ Unnecessary personal data is redacted before sharing
  • ☐ Documents aren't shared with more recipients than necessary

Security of Processing (Article 32)

  • ☐ Sensitive documents are encrypted in transit and at rest
  • ☐ Access is limited to authorized personnel only
  • ☐ Metadata containing personal data is removed before external sharing
  • ☐ Document transmission logs are maintained

Retention & Erasure

  • ☐ Retention period is defined for this document type
  • ☐ Documents are deleted when retention period expires
  • ☐ Process exists to respond to right-to-erasure requests (RTBF)
  • ☐ Backups are updated when documents are erased from primary storage

Data Subject Rights

  • ☐ Process for responding to subject access requests (SARs) within 30 days
  • ☐ Ability to provide a copy of all personal data in a document upon request
  • ☐ Process for correcting inaccurate personal data in documents

High-Risk Document Types

These document types require extra care: medical records, HR files, legal contracts with personal data, financial statements, background check reports, authentication logs.

FAQ

Does encrypting a PDF make it GDPR compliant?
Encryption satisfies the Article 32 "appropriate technical measures" requirement, but GDPR compliance requires addressing all principles: lawful basis, purpose limitation, data minimization, retention, and data subject rights.
Do I need a DPA for document processing tools?
If you use a third-party tool to process PDFs containing personal data, and that tool processes the data on your behalf, yes — you need a Data Processing Agreement (DPA). DocInspector processes documents client-side or in isolated environments.
