Frequently Asked Questions

The browser tools support PDF, DOCX, XLSX, JPG, PNG, and TIFF for metadata sanitization. Watermark, encrypt, redact, flatten, and repair operations currently support PDF. The Bundle Summary and Folder Evidence tools work with any file type. The desktop application supports all these formats plus full batch processing capabilities.

No installation is required. The online tools run entirely in your web browser using modern JavaScript and WebAssembly. Any modern browser (Chrome, Firefox, Edge, Safari) works. For the full desktop application with advanced features like OCR and recursive folder scanning, a Windows installer is available.

Yes. Because the browser tools process files entirely within your browser with zero server uploads, there is no data collection or transfer involved. The desktop application processes files locally on your machine. Both approaches are fully GDPR compliant by design.

Document metadata includes hidden information embedded in files — author names, creation dates, GPS coordinates (in images), revision history, software versions, and internal comments. Removing metadata protects privacy, prevents unintended information leakage, and is often required for legal evidence submission and regulatory compliance.

The Advanced Borderou is a detailed inventory report generated as an Excel spreadsheet. It catalogs all files in a selected folder with comprehensive metadata including file names, sizes, types, creation dates, modification dates, SHA-256 hash values, and page counts for documents. It's essential for legal evidence management and compliance auditing.

The Folder Evidence Report is a comprehensive Excel-based audit trail that documents the complete directory structure, file integrity hashes, and metadata for all files in a folder tree. It provides a court-ready snapshot of folder contents and is designed for legal evidence management, chain-of-custody documentation, and compliance requirements.

File format conversions including Word to PDF, Excel to PDF, and Image to PDF are currently in active development for the browser tools and will be available in a future update. In the meantime, these conversion features are already fully available in the desktop application.

Browser Tools are free, require no installation, and handle core operations like sanitize, watermark, encrypt, redact, flatten, and repair for individual files. The Desktop App is a licensed Windows application offering advanced features including OCR, batch processing of entire folder trees, recursive scanning, format conversions, secure file deletion (DoD-grade shredder), and full system auditing.
