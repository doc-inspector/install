Document metadata includes hidden information embedded in files — author names, creation dates, GPS coordinates (in images), revision history, software versions, and internal comments. Removing metadata protects privacy, prevents unintended information leakage, and is often required for legal evidence submission and regulatory compliance.

The Advanced Borderou is a detailed inventory report generated as an Excel spreadsheet. It catalogs all files in a selected folder with comprehensive metadata including file names, sizes, types, creation dates, modification dates, SHA-256 hash values, and page counts for documents. It's essential for legal evidence management and compliance auditing.

The Folder Evidence Report is a comprehensive Excel-based audit trail that documents the complete directory structure, file integrity hashes, and metadata for all files in a folder tree. It provides a court-ready snapshot of folder contents and is designed for legal evidence management, chain-of-custody documentation, and compliance requirements.

File format conversions including Word to PDF, Excel to PDF, and Image to PDF are currently in active development for the browser tools and will be available in a future update. In the meantime, these conversion features are already fully available in the desktop application.

Yes. All browser-based tools support batch processing — you can upload up to 100 files simultaneously and apply any operation to all of them in a single run. Free users get 100 files/day; Pro license users have no daily limit.

Yes. DocInspector supports a multi-operation pipeline — you can select several operations (e.g. sanitize metadata + add watermark + encrypt) and apply all of them to your batch of files in a single run, without re-uploading anything.

Yes. Beyond fixing structural corruption, the repair tool applies OCR (Optical Character Recognition) to scanned or image-based PDFs. This converts visual content into real, searchable, selectable, and copiable text — all in one step, without a separate OCR tool.

This happens when a PDF was created from a scan or a photo — the text is an image, not real characters. Use the Repair & Rebuild tool with OCR enabled: it will convert that image-text into real, copiable text without needing any separate software.

Yes, redaction is permanent and forensically sound. The tool finds keywords or regions you specify and replaces them with solid black bars, then flattens the PDF so the hidden content cannot be extracted or recovered. This is suitable for legal, compliance, and court submission use cases.

The Encrypt PDF tool applies AES-256 encryption with a password you set. It supports both user password (required to open the file) and owner password (controls printing, copying, and editing permissions). The encryption is fully compatible with Adobe Acrobat and all standard PDF readers.

Flatten PDF converts all interactive elements (form fields, annotations, signatures) into static content — the visual appearance is preserved but the elements become non-editable. Repair PDF fixes structural corruption in the file itself (broken cross-reference tables, truncated streams) and optionally applies OCR to make text selectable. They solve different problems and can be combined in the pipeline.
