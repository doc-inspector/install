Our Security Commitments

🛡️
No Persistent Storage
Files are stored only in RAM or a short-lived temp directory. Deleted automatically 5 minutes after processing — or immediately upon download.
🔒
Encrypted in Transit
All uploads and downloads use HTTPS/TLS. Your document never travels in plaintext over the network.
🚫
No AI, No Training
We use deterministic CLI tools (qpdf, ExifTool, Ghostscript). Your documents are never fed into any machine learning model.
🇪🇺
GDPR Compliant
We don't collect, store or log file contents. Processing is stateless and private by design.
⚙️
Open CLI Engines
ExifTool, qpdf, Ghostscript — battle-tested open-source tools used worldwide by security professionals.
🔍
Audit-Ready Logs
For the desktop app: every operation is logged with timestamp and SHA-256 hash for full chain-of-custody.
