Folder Evidence Mapping Guide

\n

Map out vast hard drives and network shares automatically.

\n
\n
❌ The Problem
\n

When auditing a seized hard drive or a massive corporate network share, manually listing tens of thousands of nested files is impossible.

\n
\n
\n
✅ The Solution
\n

The Folder Evidence scanner recursively dives through every subfolder, documenting paths, file sizes, and extensions, outputting a complete architectural map.

\n
\n
\n
⚙️ How it Works
\n
    \n
  • Open the DocInspector Desktop Application.
    • \n
  • Select the Folder Evidence tool and point it to a root directory or drive letter.
    • \n
  • The scanner traverses the entire tree at lightning speed.
    • \n
  • Export the complete directory map to Excel for auditing and filtering.
