# DocInspector

**DocInspector** is an offline Windows batch document processing tool designed for legal teams, compliance officers, and IT administrators. 

## Key features
- **Batch PDF repair** & hardening for corrupted or scanned files
- **Batch watermarking** for drafts and confidential evidence
- **PDF redaction** & text flattening (converting to image-only PDF)
- **Metadata sanitization** (removes hidden EXIF, author, GPS from PDF, DOCX, XLSX, JPG, PNG, TIFF)
- **Word, Excel and PowerPoint to PDF conversion**
- **OCR** for scanned PDF documents
- **Folder evidence reports** with hash checksums for audit trails
- **100% Offline processing** for maximum data security
